The OpenMath Standards

OpenMath Standard

The Normative version of the OpenMath Standard is
OpenMath Version 2.0 Revision 2.

Older versions:

OpenMath Version 2.0 Revision 1. OpenMath Version 2.0, OpenMath Version 1.1, OpenMath Version 1.0

Symbolic Computation Software Composability Protocol (SCSCP)

The current edition of the Symbolic Computation Software Composability Protocol is SCSCP Version 1.3.

SCSCP Version 1.1 and SCSCP Version 1.2 are also available.

For further information, see the SCSCP page here.

Associated Documents

  • A Type System For OpenMath. This document describes a formal type system with dependent function types and products, based on the Extended Calculus of Constructions, which can be used to augment the information in content dictionaries.
  • A Small OpenMath Type System. As an alternative to the “ECC” type system we also propose a “Small Type System” that is a more light weight system, specifically designed to be used with OpenMath objects.
